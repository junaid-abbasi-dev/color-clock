# Color Clock

A React clock that shows the current date and time.

## How to run

1. Open a terminal in this project folder.
2. Install the dependencies:

```bash
npm install
```

3. Start the app:

```bash
npm run dev
```

4. Open the local address printed in the terminal. It is usually [http://localhost:5173/](http://localhost:5173/).

To stop the app, click the terminal and press `Ctrl + C`.
